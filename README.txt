# Birthday Website — For Mas Ardha

## Struktur folder
- `index.html` — struktur delapan scene.
- `style.css` — tampilan, responsif, dan animasi.
- `script.js` — navigasi, game kunci, kalender, dan musik.
- `assets/ardha-photo.jpg` — foto yang kamu unggah.
- `assets/flower-bouquet.svg` — ilustrasi buket bunga.
- `assets/birthday-music.mp3` — opsional; tambahkan sendiri jika ingin musik.

## Menjalankan di VS Code
1. Ekstrak folder `birthday-website`.
2. Buka folder tersebut di VS Code.
3. Pastikan ekstensi **Live Server** sudah terpasang.
4. Klik kanan `index.html` → **Open with Live Server**.

## Foto
Foto yang kamu kirim sudah dipasang sebagai `assets/ardha-photo.jpg`. Jika ingin menggantinya, simpan foto baru dengan nama dan lokasi yang sama.

## Musik (opsional)
Masukkan file audio MP3 ke folder `assets`, lalu beri nama `birthday-music.mp3`. Tombol musik baru akan memutarnya setelah pengunjung menekan tombol Music. Tanpa file musik, website tetap dapat digunakan.

## Game kunci
Kode yang benar sesuai brief adalah `151225`. Jawaban salah tidak akan membuka scene berikutnya.

## Publikasi online
- **GitHub Pages:** buat repository, unggah seluruh isi folder, lalu buka Settings → Pages dan pilih branch utama serta root folder.
- **Netlify:** buka Netlify, pilih Add new site → Deploy manually, lalu seret folder `birthday-website` (atau hasil ekstraknya) ke area deploy.

Catatan: Google Fonts membutuhkan koneksi internet; jika offline, website memakai font fallback.
